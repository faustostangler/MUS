# ADR-004: Library Topology, Canonical Naming, and Stem Triplet Synthesis

**Status:** Accepted (2026-10-14, approved by Lead Architect)
**Date:** 2026-10-14
**Decision Makers:** Lead Architect (Fausto Stangler), High-Performance Implementer (AI pair)
**Supersedes:** ADR-002, ADR-003 (amended storage path and naming convention)
**Superseded by:** —

## Context

In ADR-002 and ADR-003, stem separation and symbolic transcription outputs were stored under `outputs/stems/{genre}/`. Several architectural and user experience friction points emerged:
1. **Directory Root:** `outputs/stems` was semantically imprecise as it contains not only stems, but full song MP3s, transcribed MIDIs, and resynthesized audition tracks. The canonical destination should be `outputs/library/`.
2. **Genre Normalization:** Genre folder names were inconsistently cased or defaulted to `Other` / raw titles, preventing uniform downstream indexing. Genre paths must strictly use lowercase slug format (`small caps`, e.g. `samba-reggae`, `pop-rock`, `jazz`).
3. **Artifact Suffix & Triplet Invariant:** Previously, synthesized MIDI stems carried the suffix `- synt.mp3`. The standard convention requires:
   - `{artist} - {track} - {stem}.mp3` (isolated stem audio from source)
   - `{artist} - {track} - {stem}.mid` (symbolic transcription of stem)
   - `{artist} - {track} - {stem} - mid.mp3` (acoustic synthesis derived from the MIDI)
   This represents exactly three files per stem for every stem (vocals, bass, drums, guitar, piano, other).
4. **Canonical Title Resolution:** YouTube Music metadata frequently provides tracks without the artist prefix in the raw title (e.g., video title `"I Miss Her"` instead of `"Olodum - I Miss Her"`). When the catalog history or tagger provides both artist and track title, the canonical file name must be `{artist} - {track}`.
5. **Percussion Synthesis Invariant:** `pretty_midi` zeroes out channels marked with `is_drum=True` during synthesis and divides by the peak amplitude, causing a `0/0 = NaN` exception in `AudioSignal`. Drums require dedicated transient synthesis (kick, snare, hi-hat) and non-zero dither fallback to guarantee `AudioSignal` invariants.

## Decision

**D1 — Canonical Library Root and Slug Genres.**
The pipeline storage root is migrated from `outputs/stems` to `outputs/library`. All genre directories are normalized using `sanitize_genre()`, transforming raw genre strings into lowercased alphanumeric slugs with single hyphens (e.g. `"Samba-Reggae"` -> `"samba-reggae"`).

**D2 — Canonical Track Title Formatting.**
`build_canonical_title(artist, track, fallback_title)` is enforced across ingestion and pipeline execution. If `artist` is known and not already contained in `track`, titles are synthesized as `f"{artist} - {track}"` to avoid missing artist metadata.

**D3 — Triplet Invariant per Stem.**
Every stem generated by the pipeline produces exactly three co-located files in `outputs/library/{genre_slug}/`:
1. `{artist} - {track} - {stem}.mp3`
2. `{artist} - {track} - {stem}.mid`
3. `{artist} - {track} - {stem} - mid.mp3`

**D4 — Drum-Aware Percussive Resynthesis & NaN Protection.**
`SynthesizeStemMidi` synthesizes drum tracks via `_synthesize_drum_instrument()`, synthesizing kick (exponential pitch-drop sine), snare (shaped noise burst + body resonance), and hi-hat (high-frequency bandpass transient). A non-zero inaudible dither floor (`1e-7`) is applied to prevent silent or unpitched renders from failing `AudioSignal`'s NaN/Inf and non-silent validations.

**D5 — Pipeline Idempotency.**
`is_track_fully_processed()` inspects `outputs/library/{genre_slug}/` and returns `True` if and only if all available stems possess both `.mid` and `- mid.mp3` companion files. When satisfied, the track is skipped in sub-second runtime.

## Consequences

### Positive
- Strict, clean, predictable folder hierarchy (`outputs/library/{genre_slug}/`).
- Consistent naming schema matching `{artist} - {track} - {stem}.{ext}` across all outputs.
- Elimination of `NaN` / `Inf` exceptions during percussion synthesis.
- Fast, deterministic pipeline skips for completed tracks.

### Negative / Neutral
- Renaming existing libraries requires directory migration (completed for `Olodum - I Miss Her`).

# SPEC-001: Source-Filter Vocal Pipeline — Test Specifications

**Linked ADR:** [ADR-001](../adr/ADR-001-source-filter-vocal-resynthesis-pipeline.md)
**Status:** Approved & Frozen (2026-10-13, calibrated by Spike-001)
**Date:** 2026-10-13
**Bounded Contexts:** shared_kernel, voice_modeling, music_transcription, instrument_rendering, stem_catalog

## 1. Overview & Objectives

Freeze the behavioral contract derived from ADR-001 consequences C1–C6 and N1–N5.
Every test file docstring must cite the spec IDs it covers (e.g. `"""Covers SK-03, VM-07."""`).

**Oracle principle:** no copyrighted audio in tests. Fixtures are synthetic signals with
known ground truth, generated by `tests/fixtures/signals.py`:
- `harmonic_tone(f0_hz, seconds, sr, n_harmonics)` — sawtooth-like sum of harmonics.
- `synthetic_vowel(vowel, f0_hz, seconds, sr, alpha=1.0)` — built with WORLD from a known
  Formant Target (all-pole SP) → ground-truth formants.
- `stepped_melody(midi_pitches, note_seconds, vibrato_cents, vibrato_hz)` — Pitch Contour
  with known notes.

## 3. Test Strategy Classification

- **Unit (domain + application, hermetic):** all SK/VM/MT/IR invariants, pure DSP functions
  (warp, LPC, segmenter, F0 ops), use cases with fake ports (in-memory `FakeVocoder`,
  `FakeAudioIO`, `FakeMidiWriter`). Mutation target: 0 survivors.
- **Integration (`@pytest.mark.integration`):** real `pyworld`, `soundfile`, `pretty_midi`
  on ≤ 2 s synthetic signals (< 5 s per test). Mutation target < 5 %.
- **External-binary (`@pytest.mark.external`, auto-skip if binary missing):** `fluidsynth`,
  `musescore`, `basic-pitch`.
- **E2E (`@pytest.mark.e2e`):** CLI via `typer.testing.CliRunner` on synthetic WAV.
- **Contract:** Shared Kernel round-trip serialization tests (JSON/npz DTO ↔ domain) acting
  as the inter-context contract (Pact deferred until a context becomes a service).
- **Property-based (`hypothesis`):** F0 ops, warp monotonicity, segmenter invariants.

## 4. Acceptance Criteria

### Stage 1 — Decomposition & Round-Trip (Sprint 1)
- **S1-01 Decompose:** Given a 2 s `harmonic_tone(220 Hz)` at 44.1 kHz, when decomposed,
  then the `ParametricVoice` has `≈ 2000/5 + 1` frames, SP width 1025, and median voiced
  F0 is within ±10 cents of 220 Hz.
- **S1-02 Input normalization:** Given stereo / 22.05 kHz / int16 input, the
  `AudioReader` adapter returns mono `float64` C-contiguous at the configured Sample Rate.
  MP3 input decodes (ffmpeg/soundfile) with identical shape semantics.
- **S1-03 Round-Trip Fidelity:** Given `synthetic_vowel(A, 196 Hz)`, when decomposed and
  resynthesized without modification, then re-analysis F0 RMSE ≤ 13.0 cents (calibrated by Spike-001)
  and MCD (mel-cepstrum order 24, voiced frames) ≤ 1.70 dB; output length = input length ± 1 frame;
  no NaN; peak ≤ 1.0. For real stems with Demucs bleed/reverb: F0 RMSE ≤ 60 cents (DIO) / ≤ 210 cents (Harvest),
  and MCD ≤ 8.5 dB.
- **S1-04 Segmentation:** Given a signal with two tones separated by 400 ms silence and
  `max_segment_seconds=30`, then 2 Analysis Segments; concatenated resynthesis keeps
  total length ± 1 frame and no click (sample jump at seams < 0.05).
- **S1-05 Memory guard:** A segment longer than `max_segment_seconds` without silence is
  force-split at the lowest-energy frame within the last 2 s. Peak RSS remains < 500 MB per 30s chunk.
- **S1-06 Cache:** Given a decomposed take, saving and loading the npz cache returns a
  `ParametricVoice` with F0 exact and SP/AP within float32 tolerance (rtol 1e-6); file
  loads with `allow_pickle=False`; cache key changes when any analysis parameter changes.
- **S1-07 Transpose (C1):** Given `synthetic_vowel(A, 220 Hz)`, transpose +5 semitones →
  re-analysis median F0 = 220·2^(5/12) ± 10 cents, and estimated F1/F2 change < 5 %
  (no chipmunk). Unvoiced frames stay 0.
- **S1-08 Phrase-end ramp:** `apply_ramp(window, semitones=-2, curve="linear")` changes F0
  only inside the window, monotonic in cents, reaching −2 st at window end ± 5 cents.
- **S1-09 F0 safety:** Modulated F0 is clipped to [f0_floor, f0_ceil] (config) and a
  `F0ClippedWarning` domain event counts clipped frames.
- **S1-10 Cleanup:** median smoothing (5 frames) and octave-jump correction: a contour
  with an isolated ±12 st spike of ≤ 40 ms is folded back to the local median.

### Stage 2 — Symbolic Transcription (Sprint 2)
- **S2-01 Track A notes:** Given `stepped_melody([60,64,67], 0.5 s, vibrato ±50 cents
  @ 6 Hz)`, Hysteresis Segmentation yields exactly 3 notes, pitches [60,64,67], onsets
  within ±20 ms of truth.
- **S2-02 Hysteresis:** deviations below `hysteresis_cents` (default 70) or shorter than
  `min_change_ms` (default 60) do not split a note.
- **S2-03 Short notes:** segments < `min_note_ms` (default 80) are merged into the
  neighbor with the closest pitch, or dropped if isolated.
- **S2-04 Gaps:** unvoiced gaps > `max_gap_ms` (default 50) end the note; shorter gaps
  are bridged.
- **S2-05 Velocity:** frame RMS in dBFS [−50, 0] maps linearly to velocity [20, 127];
  a +6 dB louder note has strictly higher velocity.
- **S2-06 Pitch bend (optional):** residual cents per note become bends at 10 ms
  resolution, range ±2 st; disabled → no bend events.
- **S2-07 Tempo Grid:** with `quantize=True` and 120 BPM, 1/16 grid: onsets snap to
  125 ms multiples; no note shorter than one grid step; monophony preserved after snap.
- **S2-08 MIDI export:** `PrettyMidiWriter` writes Type 1 with tempo meta event and the
  configured GM program; re-reading the file reproduces pitches/onsets (±1 tick).
- **S2-09 Track B (external):** `basic-pitch` adapter on `harmonic_tone` returns a
  `NoteSequence` whose dominant pitch equals the truth; adapter output is translated
  into Shared Kernel types only (ACL).
- **S2-10 Score export (external):** `MuseScoreCliExporter` converts `.mid` → `.mscz`
  and `.musicxml` with exit code 0; file non-empty. Missing binary → `ExternalToolMissingError`
  with an install hint, raised at composition time (fail-fast).

### Stage 3 — Formant Modeling (Sprint 3)
- **S3-01 α scaling (C4):** SP with a single peak at 1000 Hz, α=1.18 → peak at
  1180 Hz ± 1 bin; α=1.0 → output equals input; total log-energy change < 0.5 dB.
- **S3-02 Warp monotonicity:** frequency maps are strictly increasing, fixed at 0 and Nyquist
  (property-based).
- **S3-03 Formant estimation:** for `synthetic_vowel(v)` for each Cardinal Vowel, LPC
  estimate of F1/F2 (LPC order 14-18 on band-limited 5.5 kHz spectrum) within ±8% (calibrated by Spike-001)
  of the generating target.
- **S3-04 Vowel substitution (warp mode):** /a/ take, window [0.5 s, 1.5 s] → /o/:
  inside the window (excluding crossfades) estimated F1/F2 within ±10 % of target×α;
  outside the window SP is bit-identical to the original.
- **S3-05 Crossfade coherence:** log-SP frame-to-frame distance at window edges ≤ the
  95th percentile of frame-to-frame distance inside the untouched region.
- **S3-06 Overwrite mode:** synthetic all-pole envelope keeps the original frame energy
  (± 0.5 dB) and spectral tilt (regression slope ± 10 %).
- **S3-07 Voice Category:** applying `VoiceCategory.SOPRANO` scales targets and SP by
  α=1.18 consistently (target table and warp use the same α).

### Stage 4 — Render Routes (Sprint 2 for 4A, Sprint 3 for 4B)
- **S4A-01 Command:** `FluidSynthCliRenderer` builds
  `["fluidsynth","-ni","-F",out,"-r",sr,"-g",gain,sf2,mid]` (no shell); unit-tested with a
  fake process runner.
- **S4A-02 Render (external):** a 3-note sequence on GM program 42 renders a WAV whose
  duration ≥ sequence length and RMS > −40 dBFS.
- **S4A-03 Missing SoundFont:** invalid `MUS_SOUNDFONT_PATH` fails at startup for render
  commands with `ConfigurationError`.
- **S4B-01 Vocalise (C5):** a `NoteSequence` [60, 62, 64] with vowels [A, I, U] builds a
  synthetic `ParametricVoice` via the same `VocoderPort`; re-analysis F0 matches notes
  ± 15 cents in steady-state; LPC F1/F2 match vowel targets ± 15 %.
- **S4B-02 Expressiveness:** portamento (default 40 ms) and vibrato (5.5 Hz, ±30 cents,
  onset delay 200 ms) parameters measurably present in the generated F0.
- **S4B-03 Vowel source:** vowels from MIDI lyric events if present, else a CLI vowel
  string, else /a/.

### Stage 5 — Unified Resynthesis (Sprint 1 engine, extended per sprint)
- **S5-01 Pipeline:** `RenderVocalTake(decompose → [pitch ops] → [formant ops] → synthesize)`
  with original AP produces a WAV at the input Sample Rate, `PCM_24` or `FLOAT`, atomic write.
- **S5-02 Determinism:** same input + same params → byte-identical output and same cache key.
- **S5-03 Loudness:** output peak-normalized to −1 dBFS only if it would clip; otherwise
  gain untouched (reported in the run summary).

## 5. Boundary Conditions & Exception Mapping

| Input | Boundary | Expected |
|---|---|---|
| Sample Rate | 22050 at domain level | `UnsupportedSampleRateError` (adapter must resample first) |
| Audio | empty / all-zero | `SilentTakeError` |
| Audio | NaN/Inf | `CorruptAudioError` |
| F0 | all unvoiced | Stage 2 returns empty `NoteSequence` + `NoVoicedFramesWarning` event |
| Semitones | ±25 | `ValueError` from VO |
| α | 0.69 / 1.41 | `ValueError` from VO |
| VowelWindow | beyond take duration | `WindowOutOfRangeError` |
| FormantTarget | F2 ≤ F1 | `ValueError` |
| NoteSequence | overlapping notes | `PolyphonyNotSupportedError` |
| External tool | binary missing | `ExternalToolMissingError` (composition root) |

## 7. Observability & Telemetry Assertions

- Each use case emits exactly one `mus_stage_duration_seconds` observation and increments
  `mus_takes_processed_total{outcome="success"|"failure"}` (verified with an in-memory
  metrics registry fake).
- `DecomposeVoice` records `mus_voiced_ratio` and `mus_f0_octave_jump_rate`.
- `ResynthesizeVoice` in round-trip mode records `mus_roundtrip_f0_rmse_cents` and
  `mus_roundtrip_mcd_db`.
- Logs are JSON with `take_id`, `stage`, `params_hash`; no absolute home paths beyond the
  configured roots.
